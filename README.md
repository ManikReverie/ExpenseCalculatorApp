# Simple Expense Calculator
## Project Overview
A simple Android app developed using Kotlin and XML for the Veda Technology Android Development Track (Day 27). It allows users to input expense amounts and categories, calculates the total, and maintains a list of entered expenses.
## Technologies Used
- Kotlin
- XML Layouts
- Android Studio
## Features
- Input fields for amount and category
- Add Expense button
- Dynamically calculates and displays the total expense
- Displays a list of all added expenses
## How to Run
1. Clone the repository. 2. Open in Android Studio. 3. Sync Gradle. 4. Run the app.
## Outcome
The application successfully tracks expenses, calculates the running total, and displays a list of records.
